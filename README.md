แอปผู้ช่วยอัจฉริยะสำหรับการจัดการการเงินส่วนบุคคลและแนะนำร้านอาหารตามงบประมาณ โดยต่อยอดจากความรู้ใน Lab GSP1150 (Introduction to Gemini 3)

---

## 1. วิธีการรันโปรแกรม (How to Run)

เพื่อให้โปรแกรมทำงานได้อย่างสมบูรณ์ โปรดปฏิบัติตามขั้นตอน ดังนี้:

1. **ทำ การ Clone Repository** นี้ลงเครื่องคอมพิวเตอร์ของคุณ:
   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. **ติดตั้ง Library ที่จำเป็น** ผ่านไฟล์ `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

3. **ตั้งค่า Environment Variable**:
   คัดลอกไฟล์ `.env.example` และเปลี่ยนชื่อเป็น `.env` จากนั้นใส่ Gemini API Key ของคุณลงไป:
   ```bash
   cp .env.example .env
   ```

4. **รันแอปพลิเคชัน** ด้วยคำสั่ง:
   ```bash
   python app.py
   ```

5. *(หรือเปิดใช้งานผ่านไฟล์ `.ipynb` บน Jupyter Notebook ตามตัวอย่างใน Lab)*

## 2. ตัวอย่าง Input/Output (Examples)

* **การบันทึกรายจ่าย:**
  * **Input:** `"วันนี้กินส้มตำไป 120 บาท"`
  * **Output (JSON):** 
    ```json
    {
      "item": "ส้มตำ",
      "amount": 120,
      "category": "อาหาร"
    }
    ```

* **การแนะนำร้านอาหาร:**
  * **Input:** `"แนะนำร้านอาหารใกล้สยามพารากอน งบไม่เกิน 300 บาท"`
  * **Output:** รายชื่อร้านอาหารพร้อมพิกัดและราคาปัจจุบันที่ดึงข้อมูลจากอินเทอร์เน็ตจริง ๆ

## 3. ฟีเจอร์จาก Lab ที่นำมาใช้ (Features from Lab)

มีการเลือกใช้ฟีเจอร์จาก Lab และสไลด์มากกว่า 3 อย่าง ดังนี้:

1. **System Instructions:** ใช้กำหนดบทบาทโมเดลเป็น "ผู้เชี่ยวชาญด้านบัญชีและการวางแผนการเงิน" เพื่อควบคุมโทนและพฤติกรรม
2. **Structured Output (JSON):** บังคับให้ AI ตอบกลับข้อมูลรายจ่ายตาม Schema เพื่อให้แอปนำไปคำนวณงบประมาณต่อได้แม่นยำ
3. **Grounding (Google Search):** เชื่อมต่อโมเดลกับข้อมูลโลกจริงเพื่อค้นหาร้านอาหารและราคาปัจจุบัน
4. **Code Execution:** ให้ AI เขียนและรันโค้ด Python เพื่อสรุปยอดรวมรายจ่ายประจำเดือนเทียบกับเป้าหมายที่ตั้งไว้
5. **Multimodality:** รองรับการวิเคราะห์รูปภาพใบเสร็จเพื่อสรุปยอดเงิน

## 4. ส่วนที่ใช้ AI ในแอป (How AI is used)

* ใช้ Gemini 3.5 Flash เป็นแกนกลางในการประมวลผล เพราะมีความเร็วสูงและฉลาดในด้านการใช้เหตุผล (Reasoning)
* ใช้ AI ในการวิเคราะห์เจตนาของผู้ใช้ (Intent Classification) ว่าเป็นการบันทึกรายจ่ายหรือการขอคำแนะนำ
* ใช้ AI ในการสกัดข้อมูลจากข้อความภาษาไทยหรือรูปภาพใบเสร็จให้เป็นข้อมูลโครงสร้าง JSON

---

## 5. การตั้งค่า Temperature และเหตุผล

* **ค่าที่ใช้:** `0.1`
* **เหตุผล:** เนื่องจากแอปเกี่ยวข้องกับการคำนวณตัวเลขและการจัดการงบประมาณ จึงต้องการความแม่นยำสูงสุด (High Precision) เพื่อป้องกันการ "หลอน" ของข้อมูล (Hallucinations) ที่อาจเกิดขึ้นหากตั้งค่า Temperature สูงเกินไป

---

## 6. ส่วนที่ AI (NotebookLM) ช่วยเหลือในโปรเจกต์นี้

ในโปรเจกต์นี้ ได้ใช้ AI ช่วยในขั้นตอนต่าง ๆ ดังนี้:

* **Brainstorming:** ช่วยขัดเกลาไอเดียแอปบันทึกรายจ่ายให้มีความเป็น Agentic AI มากขึ้น
* **Drafting Documents:** ช่วยร่างโครงสร้างไฟล์ `SPEC.md` และ `README.md` ตามเกณฑ์ที่ได้รับมอบหมาย
* **Prompt Engineering:** ช่วยออกแบบ System Instruction และกำหนด JSON Schema สำหรับการทำงานระดับมืออาชีพ
* **Technical Consulting:** ช่วยสรุปและดึงขั้นตอนการใช้ฟีเจอร์ Grounding และ SDK จากแหล่งข้อมูลใน Lab

---

## 7. การประเมินคะแนน R / D / T + การใช้ AI

* **R (Reasoning/Responsibility):** ใช้โมเดลที่มีความสามารถด้าน Reasoning สูง และใส่ Safety Filters เพื่อป้องกันเนื้อหาที่ไม่เหมาะสม
* **D (Determination):** เพิ่มฟีเจอร์ขั้นสูงอย่าง Grounding และระบบบันทึกรายจ่ายจากภาพ (Multimodality) ที่ซับซ้อนกว่าโจทย์พื้นฐาน
* **T (Technical):** มีการจัดการข้อมูลผ่าน Structured Output และใช้ `.env` เพื่อรักษาความลับของ API Key
* **การใช้ AI:** ระบุส่วนที่ AI มีส่วนร่วมอย่างชัดเจนในข้อ 6 เพื่อความโปร่งใสและแสดงทักษะการทำงานร่วมกับ AI
